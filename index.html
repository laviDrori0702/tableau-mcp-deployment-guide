Self-Host Tableau MCP

Run one Tableau MCP server beside your Tableau Server, and everyone in your org can ask Claude Code or Cursor about Tableau content, each signed in as themselves. Plan about two hours plus one Tableau Server restart.

At a glance

You run the middle box. No shared password exists anywhere: each user signs in to Tableau once, and the MCP server then works with that user's own permissions.

Your values

Every <placeholder> below stands for one of these. Write yours down first; the examples are fictional.

PlaceholderWhat it isExample
<tableau-url>Your Tableau Server addresshttps://tableau.example.com
<site>Site URL-name, the part after /#/site/. Empty for the Default siteSales
<mcp-host>Full DNS name of the machine running MCP. Must be in its certificatemcp.corp.example.com
<port>Port MCP listens on3927 (the default)
<install-dir>Folder for the server on that machineC:\tableau-mcp

The address users connect to is https://<mcp-host>:<port>/tableau-mcp, for example https://mcp.corp.example.com:3927/tableau-mcp.

Before you start

  • Tableau Server 2025.3 or newer. Per-user sign-in (OAuth) needs it. Check with tsm version.
  • Node.js 22.7.5 or newer on the MCP machine: node --version. The Tableau Server host itself works fine.
  • A TLS certificate for <mcp-host>: the key, plus the certificate with its chain, as PEM files. Ask whoever issues your internal certificates.
  • Tableau admin rights to run tsm, and local admin on the MCP machine.
  • A maintenance window. Step 3 restarts Tableau Server once. Nothing else here touches Tableau users.
  • Firewall: your workstations must reach <mcp-host>:<port>, and the MCP machine must reach <tableau-url>.

Set it up

Run everything in an elevated PowerShell on the MCP machine, except step 3, which runs on the Tableau Server host.

1. Install the server

Pin a version so a restart never upgrades by surprise. Check npm for the latest; 6.0.4 is shown here.

New-Item -ItemType Directory -Force <install-dir>
Set-Location <install-dir>
npm install @tableau/mcp-server@6.0.4

2. Create the sign-in key

The server encrypts users' access tokens with this key. It is a secret: anyone holding it can forge access. Never share or commit it.

New-Item -ItemType Directory -Force certs
node -e "const{generateKeyPairSync}=require('crypto');const{privateKey}=generateKeyPairSync('rsa',{modulusLength:2048});require('fs').writeFileSync('certs/oauth-jwe-private.pem',privateKey.export({type:'pkcs1',format:'pem'}))"

3. Let Tableau send sign-ins to the MCP host

On the Tableau Server host, as a Tableau admin. apply restarts Tableau Server and ships everything staged, so list first.

tsm pending-changes list
tsm configuration set -k oauth.allowed_redirect_uri_hosts -v <mcp-host>
tsm pending-changes apply

Host name only: mcp.corp.example.com, not https://mcp.corp.example.com:3927.

4. Add the certificate

Copy two PEM files into <install-dir>\certs:

  • mcp.key: the private key, without a passphrase.
  • fullchain.pem: the server certificate first, then any intermediate certificate, in one file.

The certificate must list <mcp-host> as a Subject Alternative Name. Users must connect with exactly that name, not an IP or a short name.

5. Write the .env file

Create <install-dir>\.env:

SERVER=<tableau-url>
SITE_NAME=<site>
TRANSPORT=http

# Per-user sign-in. OAUTH_ISSUER is the MCP server's own address, not Tableau's.
AUTH=oauth
OAUTH_ISSUER=https://<mcp-host>:<port>
OAUTH_RESOURCE_URI=https://<mcp-host>:<port>
OAUTH_JWE_PRIVATE_KEY_PATH=<install-dir>\certs\oauth-jwe-private.pem

# HTTPS. These exact names; anything else silently serves plain http.
SSL_KEY=<install-dir>\certs\mcp.key
SSL_CERT=<install-dir>\certs\fullchain.pem

# Optional: hide tools Tableau Server can't use
EXCLUDE_TOOLS=pulse

Filled in, the first lines read SERVER=https://tableau.example.com and OAUTH_ISSUER=https://mcp.corp.example.com:3927. Add PORT=<port> only if you don't use 3927.

6. Start it and check

Set-Location <install-dir>
node --use-system-ca node_modules\@tableau\mcp-server\build\index.js

--use-system-ca makes Node trust your company's internal certificate authority when it calls Tableau. The startup line must say https://.

From a workstation, this must print 401, meaning the server is up and asking for sign-in:

try { Invoke-WebRequest -UseBasicParsing -Method POST -Uri https://<mcp-host>:<port>/tableau-mcp -ContentType application/json -Headers @{Accept='application/json, text/event-stream'} -Body '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"test","version":"1"}}}' } catch { $_.Exception.Response.StatusCode.value__ }

Run it at boot

Started by hand, the server stops when you log off. A scheduled task running as SYSTEM keeps it up with nobody logged in. Stop the hand-started server first (Ctrl+C), then in an elevated PowerShell:

# 1. SYSTEM must read the secrets and write logs
icacls <install-dir> /grant "SYSTEM:(OI)(CI)(R)"
New-Item -ItemType Directory -Force <install-dir>\logs
icacls <install-dir>\logs /grant "SYSTEM:(OI)(CI)(M)"
Add-Content <install-dir>\.env "`nENABLED_LOGGERS=appLogger,fileLogger`nFILE_LOGGER_DIRECTORY=<install-dir>\logs"

# 2. Register and start the task
$node = (Get-Command node).Source
$action = New-ScheduledTaskAction -Execute $node -Argument "--use-system-ca node_modules\@tableau\mcp-server\build\index.js" -WorkingDirectory "<install-dir>"
$settings = New-ScheduledTaskSettingsSet -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1) -ExecutionTimeLimit ([TimeSpan]::Zero)
Register-ScheduledTask -TaskName TableauMCP -Action $action -Trigger (New-ScheduledTaskTrigger -AtStartup) -Settings $settings -User SYSTEM -RunLevel Highest
Start-ScheduledTask -TaskName TableauMCP

Check it with Get-Content <install-dir>\logs\*.log -Tail 20: the startup line must say https://. Then repeat the 401 check from step 6.

Three things that break it

  • --use-system-ca must sit in -Argument. It does nothing in .env.
  • -ExecutionTimeLimit ([TimeSpan]::Zero) matters: without it, Windows stops the task after three days.
  • To restart, run Stop-ScheduledTask then Start-ScheduledTask. Every restart signs all users out, so batch config changes.

Connect users

Send your users the address and one of these. Nobody needs a password or token in the config: the first Tableau question opens a browser to sign in.

Claude Code (-s user makes it work in every folder):

claude mcp add -s user --transport http tableau https://<mcp-host>:<port>/tableau-mcp

Then run /mcp, pick tableau and choose to authenticate.

Cursor: add to %USERPROFILE%\.cursor\mcp.json, then restart Cursor:

{
  "mcpServers": {
    "tableau": { "url": "https://<mcp-host>:<port>/tableau-mcp" }
  }
}

The check that proves it works: ask "List our Tableau datasources, then query one." Seeing the tool list is not enough, because it loads without contacting Tableau. Only data coming back proves the whole path.

Each user sees only what their own Tableau account can see, so a permission error is usually correct.
